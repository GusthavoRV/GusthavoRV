## O que eu construo

- SaaS multi-tenant em TypeScript (NestJS, Fastify, Next.js, React Native/Expo) com PostgreSQL, Redis e filas (BullMQ).
- Integrações do mercado brasileiro: NF-e, NFS-e e SEFAZ (Focus NFe), Open Finance (Pluggy, Lina), PIX e cobrança (Asaas), Tiny ERP.
- Arquitetura com DDD, contract-first (oRPC + Zod), monorepo pnpm/Turborepo, offline-first no mobile, RBAC, auditoria imutável e LGPD.
- Infra e CI/CD completos: Docker, Nginx/Traefik, GitHub Actions, release semântico e deploy automático em VPS.
- Quando o problema pede, saio do JavaScript: Go, Rust, Python e Flutter.

## Como eu trabalho

- Regra que importa vira trava de CI: lint próprio, dependency-cruiser, testes que provam que a guarda dispara.
- Eu opero o que escrevo: runbook, monitoramento e postmortem fazem parte da entrega.
- Documentação junto do código: ADRs numerados, wiki versionada, log de decisões.
- Uma auditoria não basta; a segunda rodada acha o que a primeira não viu.
